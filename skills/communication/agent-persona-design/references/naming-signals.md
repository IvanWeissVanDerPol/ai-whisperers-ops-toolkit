# Naming Signals — Session History

## May 2026 — Erebus persona creation

**Context:** Creating an AI workforce lead persona for Ai-Whisperers (Paraguay-based AI web agency).

**Rejected names:**
- Verá (Guarani for "flash") — user said "dont be guarani or paraguay"
- Sunstein — already a repo name in the org (sunstein repo created same day)
- Onyx — not rejected but Erebus won

**Accepted name:**
- Erebus — Greek primordial of darkness. User's own suggestion after I proposed Onyx. User said "what about erebus it was previusly your choice" — I'd proposed Erebus in an earlier session but abandoned it.

**Key lesson:** When the user rejects a naming direction (cultural, thematic), DO NOT present another option in the same direction. The rejection was of the category, not the specific name. Move to a completely different category.

**Key lesson:** Before proposing ANY name, check GitHub org repos, Docker services, and domain names. "Sunstein" was rejected because it's already a repo.

**Key lesson:** If you proposed a name in a previous session and the user engaged with it, don't discard it. Re-propose before starting fresh research. The user may remember and prefer it.
