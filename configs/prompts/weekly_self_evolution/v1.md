STEP 1: Run `python3 ~/.hermes/skills/hermes-dojo/scripts/monitor.py` to scan recent sessions (last 7 days). Generate a JSON report on per-tool success/failure rates, error patterns, and user correction signals.
STEP 2: Identify the top 3 weaknesses (lowest success rate OR most user corrections).
STEP 3: For each weakness, decide the fix:
  - Existing skill failing → patch it with skill_manage action='patch' to add error handling or edge cases
  - No skill exists for a recurring need → create one with skill_manage action='create'
STEP 4: Log provenance to ~/.hermes/logs/dojo-provenance.log: timestamp, weakness, action, target skill.
STEP 5: Re-run monitor.py and compute new metrics. If improvement < 5%, flag for manual review.
STEP 6: Deliver the report to local. Format: success rates before/after, list of patches created, list of new skills, learning curve.
